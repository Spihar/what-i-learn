**VIBE CODING VS AGENTIC CODING**

today I watched video about the difference between vide coding and agentic coding

**Vibe Coding**

Focuses on using AI to generate code through natural-language prompts.

Often involves describing what I want and letting AI generate the implementation.

I may not deeply inspect or understand every part of the generated code.

The main focus is speed and getting something working.


**Agentic Coding**

AI agents work toward a goal by planning, executing tasks, using tools, and iterating.

The AI can inspect the codebase, modify files, run commands, test the implementation, and correct errors.

The process is more structured and involves giving the AI a goal while allowing it to perform multiple steps autonomously.


**RAG vs Fine-tuning Vs prompt engineering**
-- using RAG, we give LLM external data
-- Using fine-Tuning we train the model on specific tasks
-- using prompt engineering, we restrict the output
